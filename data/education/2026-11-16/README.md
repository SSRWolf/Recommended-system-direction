# 教育数据集工作簿的可复现摘要

分析日期：2026-11-16。来源：用户提供的 `E:\postgraduate\教育类数据集_表头与前五条_含字段说明.xlsx`，已实际读取所有工作表。

- [field-catalog.md](field-catalog.md)：完整字段、原字段解释、原列序、来源与覆盖表、共同字段表，以及样例空值计数。
- [workbook-summary.json](workbook-summary.json)：同一结果的机器可读版本，含原 Excel 的 SHA-256。
- [数据适配分析](../../../docs/education/2026-11-16/datasets.md)：粒度、事件还原、表关联、泄漏风险与六方向适配矩阵。

共 33 个工作表：2 个元数据表、31 个数据/字段表；其中 26 个含样例、5 个仅有表头和解释。24 个表各有 5 行样例，2 个表各有 4 行，共 128 行。它们包括内容元数据和同一来源的不同粒度视图，不能相加为“128 次独立学生行为”。

`来源与覆盖` 有 33 项，其中 DBE-KT22 原始表和 Foundational_技能没有对应数据工作表；不要把“覆盖表列出”当作“已读取原始记录”。EdNet 是官方 README 样例，Algebra06 是文档展示行；本次并未下载各数据集全量文件或重新确认每个源 URL 的下载状态。

本目录选择保存用户允许的“可复现摘要”：全部字段、说明、出处和样例结构统计，不保存逐条学生样例或复制 Excel。原表的字段解释是来源记录；人工分析中的修正单独写入 datasets.md。缺失标记统计仅识别空单元格以及去空白、不区分大小写的 `NaN/NA/null/空字符串`，不擅自将 -1、0 等判为缺失。

## 重现

Python 3.12，openpyxl 3.1.5。安装 `openpyxl==3.1.5` 后，在仓库根目录运行：

```powershell
python scripts/export_education_workbook_summary.py "E:\postgraduate\教育类数据集_表头与前五条_含字段说明.xlsx"
```

脚本只读 Excel，输出上述两份摘要；不访问网络、不修改源文件。对同一字节内容的源文件，输出应逐字节一致。复核 SHA-256 时应比较文件字节，而不只是文件名。字段表第二行是说明，从第三行才是样例；元数据表从第二行开始是元数据。
