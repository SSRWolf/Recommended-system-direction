## 2. 与当前选题的联系

RAG 在推荐中可以承担不同作用：

- **改善推荐匹配**：检索用户历史、相似用户或相关物品，为推荐决策补充信息。
- **支持有依据的回复**：检索物品属性、评论或知识库，支持对推荐对象的描述与解释。

例如，“这部电影符合你喜欢悬疑片的偏好”涉及匹配用户偏好；“电影由谁执导、是否获得某个奖项”涉及可核查的事实。Gen-RecSys 第 3.3 节也讨论了用户记忆与物品评论的检索用途。

此前阅读的一般 RAG 综述用于理解检索与生成技术，本页的综述用于衔接推荐任务。建议首先阅读中文专门综述，再按具体问题追踪方法论文，不必一次精读全部综述。

## 3. 阅读记录表

| 记录项 | 要回答的问题 |
|---|---|
| 检索对象 | 检索用户历史、物品信息、评论，还是知识图谱？ |
| 检索依据 | 使用当前一句话，还是完整对话与用户偏好？ |
| 生成内容 | 输出物品列表、推荐理由，还是完整对话回复？ |
| 幻觉评估 | 是否验证物品存在性、属性准确性、理由的证据支持？ |
| 推荐效果 | 减少幻觉后，推荐准确率与用户满意度是否保持？ |
| 实验边界 | 知识库来自哪里？是否使用了目标答案或未来对话？ |

应区分“推荐指标提高”和“生成内容更有事实依据”。研究表述优先使用“缓解幻觉”或“提升事实一致性”，RAG 本身不保证消除幻觉。上表是后续阅读与实验设计建议，不是对上述综述已有实验结论的转述。
