# 行为子集与推荐刻板印象放大的研究讨论

整理日期：2026-11-03

本笔记讨论如何从用户历史行为中寻找一组会强化推荐刻板关联、压制其他兴趣的交互，并探索可解释的干预方式。目前属于问题定义和文献调研阶段，尚未开展实验；以下指标是候选设计，不是公认标准，也不代表已确认的创新点。

## 1. 行为子集具体是什么

行为子集是从用户完整历史中选出的若干交互事件。它可以不连续，也可以跨越商品类别。

一个事件可写为：

$$b_t=(i_t,a_t,\tau_t)$$

其中 $i_t$ 是商品，$a_t$ 是浏览、收藏、购买等动作类型，$\tau_t$ 是时间。相同商品的两次浏览属于两个不同事件。

假设完整历史为 $H=(b_1,\ldots,b_6)$：

| 编号 | 时间 | 行为 |
|---|---|---|
| $b_1$ | 周一 | 浏览口红 |
| $b_2$ | 周二 | 收藏编程书籍 |
| $b_3$ | 周三 | 购买职场衬衫 |
| $b_4$ | 周四 | 浏览露营帐篷 |
| $b_5$ | 周五 | 购买连衣裙 |
| $b_6$ | 周六 | 点击电子开发板 |

选择位置集合 $J=\{1,3,5\}$，对应行为组合为 $S=(b_1,b_3,b_5)$。这里用位置索引区分重复发生的事件。

删除后，保留其余事件的原有顺序：

$$H_{-J}=(b_2,b_4,b_6)$$

上述例子仅演示子集的构造，不表示这些商品一定导致刻板印象，也不能据此确定用户的性别、收入和职业。

### 三种选取方式

| 类型 | 示例 | 解释 |
|---|---|---|
| 连续片段 | $(b_2,b_3,b_4)$ | 相邻的一段历史 |
| 不连续子集 | $(b_1,b_3,b_5)$ | 不同位置的若干事件 |
| 语义相关子集 | 与工作通勤需求有关的多个事件 | 由共同需求或情境组织，需要验证语义关系 |

研究目标可表述为：发现对特定刻板关联强化具有较大影响、规模较小且有可解释语义的历史行为组合。“影响大”“规模小”“语义一致”需要分别验证。

## 2. 从行为组合到高阶语义

商品类目描述“商品是什么”；高阶需求描述“这些行为可能共同服务什么目的”。

| 行为组合 | 可能的需求或情境解释 |
|---|---|
| 衬衫、电脑包、通勤鞋 | 工作通勤 |
| 帐篷、露营灯、便携炊具 | 户外过夜活动 |
| 咖啡豆、手冲壶、滤纸 | 居家咖啡制作 |

这些解释是候选语义，而不是用户身份事实。送礼、代购、共享账户和临时需求均可能产生相同记录。更高的抽象层级也不自动保证普适性、鲁棒性或因果真实性。

可探索的链条为：

行为片段 → 有证据支持的需求概念 → 概念分离与表示 → 检查覆盖偏差 → 可控干预。

## 3. 为什么需要比较完整历史与删除后的历史

固定训练好的推荐模型 $f$，分别生成：

$$L_H=f(H), \qquad L_{-J}=f(H_{-J})$$

比较推荐列表的变化，以检查该子集对模型输出的影响。

例如，保留某子集时，推荐更集中于某种群体关联内容，同时其他已确认兴趣的覆盖下降；删除后，这种情况缓解。该子集可以作为进一步审计的候选。

不能仅凭“美妆曝光增加”判定刻板印象，因为这可能是正常个性化。应区分真实需求的更新与由有限线索引发的过度概括。

删除实验首先揭示模型的输入依赖，并不自动识别现实世界中的因果作用。

## 4. 候选指标与验证设计

### 4.1 刻板关联曝光

设 $c_g(i)\in[0,1]$ 表示商品与群体 $g$ 的社会刻板关联强度。该分数需要独立标注或外部研究依据；它不是“该群体应该喜欢此商品”的判断。

$$E_g(L)=\frac{\sum_{r=1}^{K}w_r c_g(i_r)}{\sum_{r=1}^{K}w_r},
\qquad w_r=\frac{1}{\log_2(r+1)}$$

该值只度量关联内容的曝光，不能单独证明不公平或伤害。

### 4.2 其他已验证兴趣的覆盖

以用户明确表达的需求、独立测试期正反馈或用户研究为依据，定义其他兴趣上的质量 $Q_{\mathrm{other}}(L)$，例如限定相关商品集合上的 Recall@K 或 NDCG@K。

定义删除效应：

$$\Delta E_g(J;f)=E_g(f(H))-E_g(f(H_{-J}))$$

$$\Delta Q_{\mathrm{other}}(J;f)=Q_{\mathrm{other}}(f(H_{-J}))-Q_{\mathrm{other}}(f(H))$$

两者同时显著为正，表示保留该子集时关联曝光更多、其他兴趣质量更低，是值得检查的现象。不要未经验证将其直接命名为已成立的“刻板印象因果效应”。

### 4.3 搜索与对照

可以在 $|J|\leq k$ 的规模约束下搜索影响较大的子集，防止删除大量历史得到平凡结果。公平性、相关性、覆盖等目标先分别报告，不急于合成一个总分。

必要对照包括：

- 随机删除相同数量的事件；
- 删除时间、商品热度、动作类型与强度相近的事件；
- 删除同类兴趣中的其他行为；
- 比较单条删除与联合删除，检查是否存在组合效应；
- 使用独立用户或数据划分验证搜索结果，避免只报告搜索过程中最大的变化。

应报告多用户统计、置信区间、历史长度变化和冷启动影响。稀少兴趣不一定被压制，也可能已经满足、具有季节性或缺乏足够证据。兴趣标签和刻板关联标签不宜全部由待评估模型自行生成。

## 5. 这项研究与推荐模型的关系

影响子集通常是模型相关的：同一历史在不同模型结构、训练目标和重排序机制下可能产生不同结果。公式中的 $f$ 不应省略其含义。

子集搜索方法可以是模型无关的黑盒方法，只要求能提交干预后的输入并获取输出。但“方法通用”不代表“发现的子集对所有模型通用”。

| 推荐器 | 可实施的输入干预 |
|---|---|
| 序列推荐器 | 删除指定事件，保留其余顺序，按模型约定更新位置与时间输入 |
| GCN 推荐器 | 删除交互边，重新计算传播；删除可能影响其他节点 |
| 仅用用户 ID 的矩阵分解 | 外部删除历史不会自动改变已有用户向量，必须明确重估或重训练规则 |

固定参数后的输入干预，与删除训练数据后重新训练，是两个不同实验问题，应分别命名和报告。

## 6. 已有工作与创新边界

以下论文说明，历史子集搜索、交互级公平解释和基于解释的干预已有研究。当前讨论不能以“首次通过删除行为解释公平性”为创新声明。

| 论文 | 已有内容 | 与本方向的区别 |
|---|---|---|
| [Learning to Counterfactually Explain Recommendations](https://arxiv.org/abs/2211.09752) | 学习历史删除对推荐的影响，寻找能够移除目标推荐的子集 | 主要解释具体商品，而非刻板关联与其他兴趣压制 |
| [GNNUERS](https://arxiv.org/abs/2304.06182) | 搜索删除的交互边，使 GNN 的群体推荐效用差距减小 | 重点是群体公平解释，而非单个用户的高阶背景语义 |
| [Counterfactual Graph Augmentation for Consumer Unfairness Mitigation in Recommender Systems](https://arxiv.org/abs/2308.12083) | 通过新增交互边连接公平解释与干预 | 添加边的群体公平目标，与候选行为组合审计不同 |
| [Counterfactual Explanation for Fairness in Recommendation](https://arxiv.org/abs/2307.04386) | 异质信息网络上的属性级公平解释，采用强化学习搜索 | 以属性为解释对象，不直接等同于行为组合 |

语义与可控性方面，可补充阅读：

- [MIND，EMNLP 2024](https://aclanthology.org/2024.emnlp-main.446/)：从共同购买与多模态信息提取以人为中心的购买意图。
- [FolkScope，ACL Findings 2023](https://aclanthology.org/2023.findings-acl.76.pdf)：购买意图知识图谱与人工质量验证。
- [MacridVAE，NeurIPS 2019](https://proceedings.neurips.cc/paper/2019/hash/a2186aa7c086b46ad4e8bf81e2a3a19b-Abstract.html)：宏观与微观解耦，宏观概念仍与商品分组密切相关。
- [Controllable Recommenders using Deep Generative Models and Disentanglement](https://arxiv.org/abs/2110.05056)：通过潜空间控制改变推荐。
- [Concept Bottleneck Models，ICML 2020](https://proceedings.mlr.press/v119/koh20a.html)：可理解的中间概念与概念级干预。

## 7. 下一步可执行的研究问题

1. 能否找到小规模、语义一致且具有联合效应的行为组合？
2. 其作用能否与正常的兴趣更新、历史缩短和近期行为效应区分？
3. 能否在保留该组合所表达的真实兴趣时，减轻对其他需求的抑制？
4. 在不同模型、时间窗口和用户群体上，该现象是否稳定？

建议先复现一个序列模型与一个反事实子集基线，验证可观测现象，再决定是否需要新的概念模块。仅替换已有方法的目标分数未必构成充分贡献；需要进一步的任务定义、方法设计及证据。

候选题目：**面向推荐刻板关联放大的语义行为子集发现与可控干预**。此题目暂定，不表示完整方案的首创性已获确认。
