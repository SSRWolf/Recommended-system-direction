## 研究主线

学生历史行为 → 知识状态与学习策略 → 潜在学习需求 → 受知识关系约束的推荐。

六个方向保留为研究地图：①多维行为需求发现；②长短期需求；③序列与知识图谱；④稳定行为模式；⑤序列推荐与 LLM 学习路径；⑥跨领域迁移。①—④主要研究表示和解释，⑤研究干预决策，⑥检验表示能否跨领域复用。

建议先用 ASSIST2012 或 Algebra05 建立①的可复现基线，随后用 OLI 操作日志或 EdNet-KT3 验证④，再推进②或③。⑥需要至少两个行为语义可对齐的领域，⑤需要可用资源库、文本与路径约束；两者均设为后续阶段。这个次序是根据当前字段可用性作出的研究建议，不是对方法效果的排名。

“快速答错=粗心”“看提示后答对=未掌握”均只是待检验解释。潜在需求向量必须通过未参与训练的后续无提示作答、跨知识点迁移题或独立测评验证。正确率预测、行为聚类和学习增益是不同评价目标。
