# 六个研究方向：问题、方法、验证

论文编号见 [papers.md](papers.md)，字段与可用性见 [datasets.md](datasets.md)。以下模型组合是实验提案；引用论文只支持相应构件或研究问题，不意味着已经证明整套方案有效。

## 1. 多维行为驱动的潜在学习需求发现

**研究思路：** 从学生的不同学习行为出发，研究作答、重试、求助、查看解析和复习等行为所反映的潜在学习需求。将正确性与用时、尝试次数、提示使用结合，分析相同作答结果背后的过程差异。

例如，同样围绕作答表现，可以提出以下待检验解释：

| 行为表现 | 潜在需求或困难的候选解释 |
| --- | --- |
| 快速答错 | 可能存在知识理解不足，也可能是粗心或猜测 |
| 长时间思考后答错 | 可能在推理过程或解题步骤上遇到困难 |
| 多次尝试后仍答错 | 可能存在持续性的知识缺口 |
| 看提示后答对 | 可能仍需帮助才能完成，需通过后续无提示作答检验独立掌握程度 |

这些例子同时涉及行为类型、用时和尝试过程；具体解释需结合题目难度及学生历史验证。

**问题：** 在控制题目难度、历史正确率和练习机会后，时间、重试、提示等行为能否提供额外信息，解释未来的独立作答困难？

**方法：** 先以 simpleKT 为基线，加入时间、尝试与提示的简单拼接，再比较交互通道和行为通道的独立编码与门控融合（DFIKT）。仅在基线稳定后增加需求原型、序列对比学习或多任务学习；明确各辅助损失预测什么，避免仅凭向量命名为“能力”。参考 P01、P10。

**数据：** ASSIST2009/2012、ASSIST2017 原始可用字段、Algebra05/06、OLI。作答前预测当前正误时不能输入当前作答用时、最终尝试数、当前提示总数；它们只能用于本次结束后的状态更新和下一步预测。

**关键实验：** 正误基线 → 加用时 → 加重试 → 加提示 → 多通道；与同参数量模型比较。测试不同知识点上的未来无提示正确率、校准和错误恢复。若去掉用时或提示没有降低测试效果，就不支持其提供增量信息的主张。若只提高 AUC，结论停留在预测增强。

## 2. 基于时间信息的长短期学习需求建模

**研究思路：** 从行为序列的时间信息出发，区分学生当前的短期需求与持续存在的长期需求。单次作答用时、相邻行为间隔、同一知识点的重访间隔和跨会话变化分别描述不同的时间尺度。

例如，最近连续答错分数题，可能对应当前需要复习分数运算；若数周内在比例、工程和行程问题上持续出现类似困难，则可进一步检验是否存在数量关系建模方面的长期需求。方向①关注不同信号提供什么信息，本方向关注这些信息如何随时间变化。

**问题：** 最近一组练习的暂时困难，与数周内持续的薄弱知识是否有不同表现？真实时间间隔是否比事件顺序更有用？

**方法：** 时间感知注意力、同知识点重访间隔、会话编码与长期状态记忆；以固定历史窗口为对照。MTKT 提供多粒度时间表征、线性衰减偏置和因果交互卷积思路；IPDGKT 提供短期激活、长期记忆交互视角。参考 P02、P04。

**数据：** ASSIST2012、Algebra、Junyi、OLI、EdNet；OULAD 只适合天/周级。ASSIST2009 的 order_id 和 ASSIST2015 的 log_id 只能表示顺序，不能据此计算遗忘间隔。

**关键实验：** 去掉真实时间、打乱间隔但保留顺序、不同历史长度、跨会话测试、短/长间隔分桶报告。会话阈值作为预注册超参数做敏感性分析；长短窗口在验证集选择。控制课程安排和题目难度，不能把间隔与错误的相关直接解释为遗忘因果效应。

## 3. 行为序列与知识图谱联合建模

**研究思路：** 从知识点之间的联系出发，将学生的练习行为序列与知识图谱结合，发现薄弱知识点及其相关的先修知识。行为序列描述学生实际怎样练习，知识图谱补充题目、知识点与知识关系。

例如，学生在多个知识点上反复出错时，可沿知识图谱检查它们是否依赖同一先修知识，再用针对该先修知识的独立作答验证薄弱点。通过这种方式，研究从“哪些题做错了”进一步走向“哪些知识关系有助于定位困难”。

**问题：** 知识的先修、层级和题目关联是否能帮助定位薄弱点，并改善新题或低频知识的预测？

**方法：** 题目—知识点二部图为第一步，序列编码器与图编码器交互，再加入有来源的先修边。区分共现、内容相似、先修三类边；不将训练出的相关边称为先修真值。可进一步比较异构图与语义交互（MHG-KT）、动态记忆图（IPDGKT）及双曲层级表征（P05）。参考 P03—P05。

**数据：** Junyi_题目的 prerequisites 是当前最直接的先修候选来源；ASSIST、Algebra、OLI 具有 KC 映射；EdNet 有 tags；MoocRadar 的 concepts 与认知维度仅有字段描述，需取得记录再使用。

**关键实验：** 无图、题目-KC 图、随机重连图、真实先修图；检验新题和稀疏知识。由行为估计的图仅在训练集建图。静态内容图可包含预测时已公开的资源，必须说明可见时间；不能加入测试正确性边。注意力权重单独不足以证明解释忠实度。

## 4. 学习行为模式挖掘与稳定性验证

**研究思路：** 从完整行为过程出发，寻找重复出现、能够反映学生学习特点的模式。以下三类轨迹用于说明待研究现象：

| 示例 | 行为序列 | 观察到的学习特点 |
| --- | --- | --- |
| 学生 A：反复练习型 | 做题 → 错误 → 重试 → 正确 → 继续练习 | 对同类题目反复尝试和练习 |
| 学生 B：提示依赖型（候选解释） | 做题 → 错误 → 看提示 → 正确 → 看解析 | 在完成练习时多次利用外部帮助 |
| 学生 C：跨知识点探索型 | 知识点 A → B → C → A → D | 在不同知识点之间频繁切换 |

研究目标是检验以下四个问题，而非预先将所有学生固定分成三类：

- 哪些行为模式具有跨时间、跨任务的稳定性？
- 哪些模式与知识掌握程度有关？
- 哪些模式预示某类学习困难？
- 不同模式能否迁移到其他学习领域？

模式用于描述特定时间窗口中的学习过程；“提示依赖”或“主动探索”等解释需进一步验证。一个学生可以在不同任务中表现出不同模式。

**问题：** “错误→重试→正确”“错误→提示→正确”“跨知识点切换”是否在不同任务中复现，且解释力超过序列长度和活动量？

**方法：** 从 n-gram 和行为计数聚类开始；再做 PrefixSpan（允许间隔的子序列需设最大间隔）、过程挖掘、序列距离聚类或 HMM。深度对比表征作为后续对照；增强不能抹去提示顺序和时间语义。参考 P06、P09、P12。

**数据：** OLI transaction、Junyi 操作日志、EdNet-KT2/3/4；ASSIST2012 actions 解析成功后可用。Algebra 的 Incorrects/Hints 是汇总计数，不能由此还原一个步骤内的“先错还是先提示”。

**关键实验：** 按学生及任务拆分，训练集发现模式，测试集测支持度、关联的未来表现、跨任务一致性；对序列长度/题目难度匹配后重测。对聚类数、相似度、最小支持度做敏感性分析，bootstrap 报告稳定性。用“本窗口具有高提示使用模式”描述状态，不给学生贴固定人格标签。

## 5. 序列推荐与 LLM 联合的个性化学习路径

**研究思路：** 将序列推荐模型与大语言模型结合，把学生的历史行为转化为动态个性化学习路径：

1. 序列模型预测下一项候选学习资源。
2. 从序列模型中提取学生的偏好与学习行为表示。
3. LLM 结合这些表示、学习目标和资源知识，生成多步学习路径；随着新行为到来更新路径。

学生最可能选择的资源与最有助于学习的资源可能不同，因此路径生成需要同时考虑知识掌握、先修关系、难度与学习目标。另一种可先行验证的实现是将挖掘出的行为模式作为显式证据，详见[序列挖掘与 RAG 思路](sequence-mining-rag.md)。

**问题：** 怎样把行为表示转成满足目标知识、先修、难度和时间预算的可执行路径？

**方法：** SASRec 或简单转移模型生成候选；知识状态和先修规则筛选；LLM 只在资源 ID 白名单中组织路径与解释；程序检查 ID 存在、先修满足、重复、总时长和目标覆盖。对照纯规则路径、纯序列排序、LLM 无状态输入与完整方案。P07 为直接相关工作；P08 提供以技能增益为奖励的 contextual bandit 思路；P11 为排序基线。

**数据：** Junyi 的先修表和资源名可构建小型图约束原型；MoocRadar/Foundational 的完整题目文本需要另行取得。EdNet 的题库字段不等于完整题干/解析正文，不能假设已有可供 LLM 阅读的内容。

**关键实验：** NDCG/Recall 衡量历史选择预测；资源合法率、先修违规率和教师盲评衡量路径合理性；前后测/干预实验才能检验学习收益。ROUGE 或模型自身估计的掌握增量不替代真实学习增益。离线 bandit 评估需行为策略概率、覆盖假设和稳健估计；当前样表不能支撑政策价值的因果结论。

## 6. 跨领域迁移的学生行为序列建模

**研究思路：** 研究可跨领域迁移的学生行为序列表示，让同一套行为建模方法在不同知识体系中发现潜在学习需求，并根据各领域的知识关系实现可控推荐。

例如，数学中的“尝试作答 → 错误 → 查看提示 → 修正”，与编程中的“运行代码 → 失败 → 查阅文档 → 修改”，可以作为共享“尝试—反馈—求助—修正”模式的研究假设。共享行为表示负责描述学习过程，各领域的知识库负责解释具体知识关系并约束推荐。

**问题：** 数学中的“错误—求助—修正”与其他领域的类似行为，能否共享表示，同时保留领域知识结构？

**方法：** 建立有 provenance 的公共行为词表，分离共享行为编码器、领域资源/KC 编码器和小型适配层。比较从头训练、源域预训练后微调、共享多任务训练、领域对抗学习与知识图适配。P13 是通用领域适配方法来源，P03/P06 是迁移和稳定性评估参考；这不等于现有文献已解决跨学科潜在需求识别。

**数据：** 可探索数学（ASSIST/Junyi）→英语（EdNet）、数学→静力学（OLI）。相同整数 ID 不跨数据集关联；不同学科知识点不强行一一对应。OULAD 的日聚合与细粒度作答不是同一动作空间，需单独粗化评估。未取得编程日志前，不把“代码调试迁移”写成已具备的实验。

**关键实验：** 源域训练，目标域预先划分适配/验证/测试；分别报告零样本与 1%、5%、10% 目标域标注预算。无监督适配使用的目标域无标签数据与最终测试访问权限写清。对多个迁移方向、正负迁移、不同学习活跃度分组报告。比较仅活动量特征，防止模型只学到日志平台差异。

## 三层解释与独立证据

| 层次 | 观测或估计 | 所需证据 |
| --- | --- | --- |
| 行为 | 用时、重试、提示、切换 | 原事件语义与时间顺序 |
| 知识状态 | 特定 KC 的掌握概率 | 校准、未来无提示作答或独立测验 |
| 潜在需求 | 跨 KC 的共同困难或策略 | 控制难度后的迁移题、外部标注、干预响应 |

“高阶需求”是研究目标，不是工作簿现有标签。建议先完成方向①+④的增量效度检验，再决定是否引入图、LLM 或跨领域训练。
