# 中文综述与相关论文链接

整理日期：2026-10-14

本清单保存对话中推荐的主要阅读入口。中文综述的书目信息已按期刊页面或论文首页核对；部分链接为期刊页面，部分为 PDF。没有将英文论文的自动翻译页面当作中文期刊综述。

## 一、优先阅读的中文综述

### 1. 推荐系统综述

- 作者：于蒙、何文涛、周绪川等。
- 刊物：计算机应用，2022，42(6)：1898–1913。
- DOI：10.11772/j.issn.1001-9081.2021040607。
- [期刊页面与 PDF 入口](https://www.joca.cn/EN/Y2022/V42/I6/1898)
- 内容：基于内容、协同过滤、混合推荐，以及 CNN、DNN、RNN、GNN 推荐模型和常用数据集。
- 阅读目的：先建立推荐算法的整体分类与基本术语。

### 2. 基于深度学习与大语言模型的序列推荐研究进展

- 作者：徐凤如、李博涵、胥帅。
- 刊物：计算机科学与探索，2025，19(2)：344–366。
- DOI：10.3778/j.issn.1673-9418.2407090。
- [中文全文 PDF（高校图书馆托管）](https://lib.zjsru.edu.cn/25-4.21-3.pdf)
- 内容：马尔可夫链、深度学习、混合模型与大语言模型下的序列推荐，以及上下文、多模态、因果推断等研究方向。
- 阅读目的：连接组内时序偏好工作与大模型推荐。
- 优先级：如果只精读一篇，优先这篇。

### 3. 对话推荐算法研究综述

- 作者：赵梦媛、黄晓雯、桑基韬、于剑。
- 刊物：软件学报，2022，33(12)：4616–4643。
- DOI：10.13328/j.cnki.jos.006521。
- [期刊页面与全文入口](https://www.jos.org.cn/jos/article/abstract/6521)
- 内容：对话推荐框架、后台对话策略、推荐逻辑、数据集与评价指标。
- 阅读目的：理解何时追问、如何使用在线反馈、何时给出推荐。
- 注意：该文早于当前大模型 Agent 热潮，适合学习问题定义和评测基础。

### 4. 基于大语言模型的推荐系统综述

- 作者：谢广明、白彦冰、吴子昂、张艳玲。
- 刊物：智能系统学报，2025，20(6)：1520–1533。
- DOI：10.11992/tis.202410007。
- [期刊页面与 PDF 入口](https://tis.hrbeu.edu.cn/oa/darticle.aspx?id=202410007&type=view)
- [期刊 PDF](https://tis.hrbeu.edu.cn/Upload/PaperUpLoad/9d63ae31-b4da-417f-b3e9-658e72a161a6.pdf)
- 内容：大语言模型与推荐系统的结合，训练、推理效率和应用效果。
- 阅读目的：思考大模型在推荐流程中的位置及其成本。

### 5. 大语言模型及其个性化推荐研究

- 作者：吴国栋、秦辉、胡全兴等。
- 刊物：智能系统学报，2024，19(6)：1351–1365。
- DOI：10.11992/tis.202309036。
- [期刊页面与中文全文入口](https://tis.hrbeu.edu.cn/oa/darticle.aspx?id=202309036&type=view)
- 内容：直接推荐、表示学习、生成性学习、提示学习，以及提示脆弱性、上下文限制、高延迟、公平性与评估问题。
- 阅读目的：补充方法分类和研究问题清单；与第 4 篇重合的部分可略读。

### 6. 多样化推荐综述

- 作者：彭迎涛、孟小峰、杜治娟。
- 刊物：计算机研究与发展，2025，62(2)：285–313。
- DOI：10.7544/issn1000-1239.202330600。
- [期刊官方 PDF](https://crad.ict.ac.cn/cn/article/pdf/preview/10.7544/issn1000-1239.202330600.pdf)
- 内容：推荐多样性的定义、技术框架、算法、数据集和评价指标。
- 阅读目的：理解准确率之外的推荐目标，以及多样性与其他目标之间的权衡。

## 二、推荐 Agent 与长期推荐的补充资料

### InteRecAgent

- [微软 RecAI 仓库中的 InteRecAgent 项目](https://github.com/microsoft/RecAI/tree/main/InteRecAgent)

- 用途：应用项目的架构参考；阅读代码不等于已经验证其可复现性。

- [论文页面：RecMind: Large Language Model Powered Agent For Recommendation](https://aclanthology.org/2024.findings-naacl.271/)
- 出处：Findings of NAACL 2024。
- 关注点：大语言模型 Agent 在推荐任务中的推理与工具使用。

### DT4Rec

- 标题：User Retention-oriented Recommendation with Decision Transformer。
- 作者：Kesen Zhao、Lixin Zou、Xiangyu Zhao、Maolin Wang、Dawei Yin。
- 出处：WWW 2023。
- [DOI 入口](https://doi.org/10.1145/3543507.3583418)
- [论文给出的代码仓库](https://github.com/kesenzhao/DT4Rec)
- 关注点：使用离线交互轨迹优化用户留存。
- 注意：推荐列表策略与对话追问策略的动作空间不同；代码链接的存在不代表已经跑通实验。

## 五、阅读与查新方法

建议顺序：中文综述 1 → 2 → 3 → 4；5、6 按需要补充。

每篇记录：

1. 任务和研究问题。
2. 输入、输出与假设。
3. 数据集、数据划分及评价指标。
4. 基线与核心方法。
5. 失败情形、成本与尚未解决的问题。
6. 与“用户状态感知记忆检索”候选题目的重合和差异。

将综述的未来方向作为检索词，再追查后续论文。发现相关新工作后，先缩小研究问题、确认基线与数据条件，再判断是否开展实验。
